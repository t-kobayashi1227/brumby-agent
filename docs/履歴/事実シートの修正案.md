## 1. 誤り・決まりへの違反（先に直す）

エージェントの判断に直接響くので、最初に直す。どれも取り込みと事実の組み立ての修正で済み、テストを付けやすい。

### 1.1 OSM の分類の誤り（L-11・L-13）

**見たこと：** L-13 コンビニの最寄りが「イオンスタイル上所 直線160m」。イオンスタイル上所はスーパー。OSM のタグ（`shop=convenience`）が誤っているものを、`scripts/ingest/jobs/osm.ts` が fclass のまま種類に直しているため。その結果、L-11 スーパーから抜け、最寄りスーパーが実際より遠い「250m」になっている。

**直し方：**

- `scripts/ingest/jobs/osm.ts` に、名前で種類を直す補正表を置く（例：名前に「イオン」「原信」「ウオロク」「ピアレ」「清水フードセンター」などを含む → スーパー）
- 補正表はファイルの先頭に定数で持ち、直した件数を取り込みの記録（`docs/data-ingest-records.md`）に残す
- 大規模小売店舗一覧（D29）に同じ店があれば、その業態を優先する案もある（1.2 の照合と合わせて検討）

**テスト：** 補正表に当たる名前が、指定の種類に直ること。当たらない名前は fclass のままであること。

### 1.2 出典をまたいだ重複（L-11・L-12・L-14・L-18）

**見たこと：**

- 「ウエルシア新潟上所中店」が L-14（大規模小売店舗一覧）で直線240m、L-12（OSM）で「ウェルシア新潟上所中店」直線350m。同じ店が、出典ごとに違う位置で入っている
- L-12「ウエルシア薬局 直線280m」と L-18「ウエルシア薬局　新潟新和店 直線290m」も同じ店の可能性がある
- L-11 スーパーと L-14 大規模小売店舗に、ピアレＭａｒｔ・マルシェコート・原信が両方出ている（種類が違うので、これは重複ではない）

`lib/facts/collect.ts` の `collectNearby` は、同じ種類の施設を出典をまたいでそのまま並べていて、重複を除いていない。

**直し方：**

- 同じ種類（kind）の中で、出典が違い、名前が似ていて（全角・半角、「ウエルシア」「ウェルシア」、空白をそろえたうえで、片方がもう片方を含む）、互いの距離が 150m 以内のものを同じ施設とみなし、1件にする
- 残す側の決まり：位置は公的データ（大規模小売店舗一覧）を優先し、名前は長いほう（店名まで入っているほう）を使う
- 重複の判定は、取り込み時に行う（物件ごとの処理を重くしないため）か、`collectNearby` で行うかを決める。区の平均（`ward_facility_averages`）にも効くので、取り込み時を推す
- 薬局（医療情報ネット）とドラッグストア（OSM）は種類が違うので、まとめない。ただし同じ店が両方に出ることは、指示文側で誤解しないよう、事実の名前で区別する（今の「ドラッグストア」「薬局」のままでよいか確認する）

**テスト：** 名前のゆれ（ウエルシア／ウェルシア、全角・半角）と距離の境目（149m・151m）。

### 1.3 バス停ののりばの重複（T-06）

**見たこと：** 「ユニゾンプラザ前 直線290m」が2回出る。上り・下りなど、のりばごとに点がある。1km以内の件数20件も、のりばの数になっていて、区の平均（32.9件）も同じ数え方。

**直し方：**

- 1km以内の一覧と件数は、停留所名でまとめて数える（同じ名前は、いちばん近いのりばの距離を使う）
- 区の平均（`ward_facility_averages` のバス停）も同じ数え方で作り直す
- 最寄りバス停（T-05）の系統数は、同じ名前ののりばの系統数を足すか、多いほうを使うかを決める（P11 の系統数の意味を `docs/参考/` で確認する）

**テスト：** 同じ名前の2点が1件に数えられること。

### 1.4 「データなし」なのに状態が「取得」（T-04）

**見たこと：** T-04 最寄り駅の乗降客数の値が「データなし」で、状態が「取得」。`lib/facts/build.ts` の 531 行目で、S12 に無い駅を文字列「データなし」にしているため、`fact()` が値ありとみなしている。CLAUDE.md の「取れなかった値は『取得できず』」に反する。

**直し方：** S12 に無い駅は値を `null` にして、状態を「取得できず」にする。「公表なし」（乗降客数 0 の駅）は、値として残すか「取得できず」にするかを決める。

**テスト：** S12 に無い駅で状態が「取得できず」になること。

### 1.5 1km の境目の表示（L-11）

**見たこと：** L-11 に「ウオロク 直線1000m」が「1km以内」として出る。判定は丸める前の値（例：996m）で正しいが、`lib/facts/format.ts` の `formatDistance` が 1km 未満を 10m 単位に丸めるので「1000m」になり、境目の外に見える。

**直し方：** 10m 単位に丸めた結果が 1000m になるときは、「直線0.99km」など1km未満と分かる書き方にする。書き方は次のどちらかに決める。

- 案A：995m 以上 1000m 以下は「直線990m」に切り捨てる（1km以内の一覧では、切り捨てで表示する）
- 案B：1km以内の一覧に限り、1m 単位で「直線996m」と書く

**テスト：** 994m・995m・999m・1000m・1001m の表示。

## 2. 誤った見立てに導きやすい点

### 2.1 相場比が土地の広さで大きく出る（M-02）

**見たこと：** 相場比 1.81倍（物件94.6万円/坪、区の中央値52.2万円/坪）。物件は延床が中央値の1.6倍（208.87㎡／130㎡）、土地が2.1倍（347.63㎡／165㎡）。延床の坪単価には土地代も入っているので、土地が広い物件ほど高く出る。M-03・M-04 で広さの中央値は並べているが、価格担当が「1.81倍の割高」と読むおそれがある。

総額の相場比は出さないと決めている（`docs/相場の出し方変更.md` 3.6）。この決定は変えず、次のどちらか（または両方）を足す。**どちらにするかは未決。**

- **案A：広さの近い取引だけの相場**
  - 区・築年数帯の取引のうち、土地面積が物件の 0.7〜1.3倍（または延床面積が 0.7〜1.3倍）のものだけで、延床の坪単価の中央値と件数を出す
  - 件数の基準（例：10件未満なら「件数が少ない」と書く、0件なら「取得できず」）は、今の M-01 と同じ決まりを使う
  - 事実の例：「M-06 広さの近い取引の相場（中央区・築20〜29年・土地243〜452㎡）中央値○万円/坪（○件）」
- **案B：土地の目安と建物分の目安**
  - 近くの基準地・公示地（M-05）の価格 × 物件の土地面積を「土地の目安」とする（今回：13万円/㎡ × 347.63㎡ ≒ 4,519万円）
  - 価格 − 土地の目安を「建物分の目安」とする（今回：約1,461万円）
  - 基準地は物件そのものの土地ではない（距離・形・接道が違う）ので、事実の名前に「目安」「近くの基準地から」と書き、距離も添える。基準地が 1km より遠いときは出さない、などの決まりを決める

案Aは取引の実データで比べられるが、件数が足りない区・帯が出る。案Bは件数に左右されないが、基準地1点に頼る。両方出すと価格担当が迷う、という 3.6 の理由にも気をつける。

### 2.2 必要年収以上の割合が全国の分布（B-05〜B-12）

**見たこと：** 住宅市場動向調査の「中古戸建を買った世帯の年収分布」は全国の値。新潟は全国より年収が低めなので、38% は甘く出ている可能性がある。

**直し方：**

- 最低限、事実の名前と出典に「全国」と書く（例：「必要年収以上の世帯の割合（全国の中古戸建の買主）」）
- 新潟県の年収分布（就業構造基本調査・住宅・土地統計調査など）で同じ割合を出せるかを `docs/参考/` に調べる。出せれば「新潟県の世帯」の割合を足す（買主の分布ではなく世帯全体の分布になる点は、名前に書く）

### 2.3 ターゲット候補ごとの返済の目安の重複（B-07〜B-12）

**見たこと：** 返済期間が同じ（35年）候補は、B-07・B-08・B-11・B-12 で数字がまったく同じ。AI への入力が長くなるだけ。

**直し方：** 返済期間ごとに1行にし、当てはまる候補を並べる（例：「【若い夫婦・小中学生のいる家族・単身・親と同居】返済期間35年。…」）。ターゲット候補ごとの行が要るかどうかは、指示文が候補名で事実を引いているかを確かめてから決める（指示文を変えるときは利用者の了承を得る）。

### 2.4 住み替え層の頭金（B-09）

**見たこと：** 頭金を一律10%にしている。50代の住み替えは、今の家を売ったお金を頭金にするのが普通で、返済額が実際より重く出る。

**直し方：** 【50代の住み替え】【60歳以上】には、頭金30%・50% の返済額・必要年収も出す。頭金の割合は `lib/calc` の定数にし、`docs/設計まとめ.md` の「買い手・ローンの前提」に書く。

**テスト：** 頭金30%・50% の返済額と必要年収。

### 2.5 買主の年代の合計が100%にならない（B-13）

**見たこと：** 30歳未満〜60歳以上の合計が 95.2%。残りは無回答と思われる。

**直し方：** 報告書で確かめ、「不明 4.8%」を値に足す。AI が残りを勝手に解釈しないようにする。

### 2.6 古いデータ（L-07・L-08・L-09）

**見たこと：** 放課後児童クラブ（2017-03）、公園・緑地（2019-12）、図書館（2019-01）。時点は表示しているが、古い。

**直し方：** 新潟市オープンデータ・国土数値情報に新しい版があるかを調べ、あれば取り替える。無ければ今のまま（時点の表示で足りる）。調べた結果は `docs/参考/` に残す。
