# 相場の出し方の変更案

2026-10-28 作成。小林さんとの相談と、DBの件数の調査をもとにまとめた案です。すべての項目が決まりました。2026-10-29 に実装し、`docs/設計まとめ.md` も直しました。

## 1. 今のやり方

`lib/facts/collect.ts`（collectMarket）と `lib/facts/build.ts`（marketFacts）で出しています。

- **対象：** 物件のある区（市区町村コード）の、種類が「宅地(土地と建物)」の取引。取り込んだ全部の年（2015〜）。取引価格情報と成約価格情報の両方
- **築年数帯：** 取引の年 − 建築年。0〜9／10〜19／20〜29／30〜39／40年以上
- **相場：** 同じ帯の取引の**総額**の中央値
- **相場比：** 物件の価格 ÷ 相場（小数2桁の「○倍」）

### 直したい点

| 点 | 内容 |
| --- | --- |
| 総額で比べている | 広い物件は割高、狭い物件は割安に見える |
| 戸建て以外が混ざる | 店舗・事務所・共同住宅などの取引も入る |
| 事情のある取引が混ざる | 調停・競売等、関係者間取引などを外していない（`data-notes.md` では外すと決めていたが、実装されていない） |
| 帯が粗い | 新築が築2〜9年の中古と同じ帯（築0〜9年）に入る |
| 時点 | 2015年と2026年の取引を同じに扱う |

## 2. 調べたこと（2026-10-28、新潟市・宅地(土地と建物)）

### 取引価格情報と成約価格情報

| | 取引価格情報 | 成約価格情報 |
| --- | --- | --- |
| どこから来るか | 国土交通省が買主に送るアンケートの回答 | 不動産会社がレインズに登録した成約 |
| 期間 | 2015〜（取り込んだ範囲） | 2021〜 |
| 件数 | 9,617件 | 937件 |
| 用途（Use） | 入っている（空は1,237件） | **すべて空** |
| 取引の事情等（Remarks） | 入っている | **すべて空** |
| 構造（Structure） | 入っている（空も多い） | 入っている（木造885件、軽量鉄骨造42件など） |

- 成約価格情報だけでは、区×築年数帯で多くのマスが10〜20件台になり、相場を出せない。
- 仲介で売れた取引は、両方に載っている（重複している）ことがある。データの中で同じ取引どうしを結び付ける方法はない。

### 町で出せるか

町（地区名 `district_name`）ごとに数えると、全部の年でも半分以上の町が10件未満だった。町の件数の中央値は2〜11.5件。**町では出さず、区で出す**ことにした。

### 区×築年数帯の件数

下の「3. 変更案」の戸建ての条件で絞ると、全部で56マスのうち、次のとおり。

| 基準 | 直近5年で足りる | 全部の年なら足りる | 全部の年でも足りない |
| --- | --- | --- | --- |
| 30件 | 32 | 16 | 8 |
| 20件 | 44 | 7 | 5（北区・南区・西蒲区の築2〜9年・築10〜19年。全部の年で11〜18件） |

件数の少ないマスは、北区・南区・西蒲区の築2〜19年に集まっている。戸建ての条件で絞ると、今のやり方より新築でわずかに、古い帯では3〜5割ほど件数が減る。

## 3. 変更案

### 3.1 範囲：区（決定）

物件のある区の取引を使う。町は件数が足りないため使わない。

### 3.2 データ：取引価格情報と成約価格情報の両方（決定）

重複の可能性は、PoCでは受け入れる。

### 3.3 戸建ての条件（決定）

| 条件 | 内容 |
| --- | --- |
| 種類 | 宅地(土地と建物) |
| 用途 | 「住宅」を含み、ほかは駐車場・倉庫・その他だけ。店舗・事務所・共同住宅・工場・作業場が付くもの（「住宅、店舗」など、約230件）は外す |
| 用途が空のとき | 構造が木造・軽量鉄骨造・鉄骨造なら入れる（成約価格情報はこれで入る）。構造も空なら外す |
| 取引の事情等 | 調停・競売等、関係者間取引、瑕疵有りの可能性、隣地の購入を外す。「私道を含む取引」は残す。成約価格情報は値が空なので外せない |
| 延床面積 | 50〜300㎡ |
| そのほか | 建築年と価格がある。取引の年 − 建築年 が0以上 |

用途が空のときに構造で判断する理由：

- 成約価格情報は用途がすべて空で、どんな建物かの手がかりは構造（と延床面積）しかない。
- 戸建ての構造は、ほとんどが木造・軽量鉄骨造・鉄骨造。ＲＣ・ＳＲＣはマンションやビルに多い。
- 用途も構造も空の取引（取引価格情報の1,073件）は、何の建物か判断できない。延床50〜300㎡に入るのも441件だけ。
- 限界：鉄骨造には店舗や倉庫もあり、ＲＣの戸建ては外れる。

「隣地の購入」を外す理由：隣の人が土地を広げるために買うため、相場と関係ない値段になりやすい。「関係者間取引」と同じく、市場で決まった値段ではない。件数は5件で、外しても件数はほとんど減らない。

SQLの条件は次のとおり。

```sql
type = '宅地(土地と建物)'
and (
  (string_to_array(raw->>'Use', '、') @> array['住宅']
    and string_to_array(raw->>'Use', '、') <@ array['住宅', '駐車場', '倉庫', 'その他'])
  or (coalesce(raw->>'Use', '') = '' and structure in ('木造', '軽量鉄骨造', '鉄骨造'))
)
and not (coalesce(raw->>'Remarks', '') like any (array['%調停%', '%競売%', '%関係者間%', '%瑕疵%', '%隣地%']))
and floor_sqm between 50 and 300
and building_year is not null and trade_price is not null
and year - building_year >= 0
```

### 3.4 築年数帯（決定）

取引の築年数は「取引の年 − 建築年」。建築年は年までしかないので、境目は少しぼやける。

| 帯 | 取引の築年数 |
| --- | --- |
| 築0〜1年 | 0〜1年（建ってすぐ売れた取引。新築の取引はここに入る） |
| 築2〜9年 | 2〜9年 |
| 築10〜19年 | 10〜19年 |
| 築20〜29年 | 20〜29年 |
| 築30〜39年 | 30〜39年 |
| 築40〜49年 | 40〜49年 |
| 築50年以上 | 50年以上 |

物件の帯は、物件の築年数（①の入力）だけで決める。物件区分（新築／中古）は見ない。

- 新築の物件は、完成から1年以内で人が住んだことのない家なので、築0〜1年の帯に入る。
- 築0〜1年の中古の物件（未入居など）も、値段が新築に近いので、同じ築0〜1年の帯と比べる。

### 3.5 年の範囲と件数の基準（決定）

1. 直近5年で20件以上 → 直近5年を使う
2. 足りなければ → 全部の年（2015〜）を使う。20件に足りなくても、そのまま出して件数を書く
3. 0件なら →「取得できず」

帯は広げない。帯を広げると築年数の違う取引が混ざり、「築10〜19年の相場」の意味がぼやけるため。今の件数では、2.で20件に足りないのは5マス（全部の年で11〜18件）。件数を理由にエージェントの自信度を下げる仕組みは、PoCでは作らない（`設計まとめ.md`「PoCで扱わないこと」）。

「直近5年」は、取り込んだ最新の年から数えて5年（今は2022〜2026）。

### 3.6 比べ方：延床の坪単価の中央値（決定）

- **取引の坪単価** ＝ 取引価格 ÷ 延床面積 × 3.30578（1坪 ＝ 400/121㎡ ≒ 3.30578㎡）
- **区の相場** ＝ 取引の坪単価の中央値（平均は、極端な取引に引っ張られるので使わない）
- **物件の坪単価** ＝ 物件の価格 ÷ 建物面積 × 3.30578
- **相場比** ＝ 物件の坪単価 ÷ 区の相場（小数2桁の「○倍」）
- 土地の広さの違いを補うため、相場に使った取引の延床面積と土地面積の中央値も並べる

総額の相場・相場比は出さない。区の総額の中央値には大きい家も小さい家も混ざるので、総額どうしの比は広さの違いがそのまま出る。相場比が2つあると、価格担当がどちらを使うか迷う。総額での手の届きやすさは、返済額・必要年収・必要年収以上の世帯の割合（B）で見る。

### 3.8 広さの近い取引の相場（2026-10-30 小林さんと決定）

延床の坪単価には土地代も入るので、広さの違う物件では相場比が読み違えられやすい（`docs/事実シートの修正案.md` 2.1）。そこで、区×築年数帯の取引のうち、広さの近いものだけの相場を足す。

- **広さの近い取引：** 延床面積が物件の 0.7〜1.3倍、**かつ** 土地面積が物件の 0.7〜1.3倍（両端を含む）。土地面積の無い取引は使わない
- **年の範囲：** 広さで絞った取引に、3.5 と同じ決まりを使う（直近5年で20件以上なら直近5年、足りなければ全部の年、0件なら「取得できず」）
- **件数が少ないとき：** 10件未満なら、値に「件数が少ない」と書く
- **値：** 延床の坪単価の中央値と件数。物件の坪単価を並べる
- **相場比は出さない：** 相場比は M-02 の1つのままにする（3.6 の「相場比が2つあると迷う」のため）。土地の目安（基準地の価格×土地面積）から建物分を引く形も、基準地1点に頼り、広い土地ほど土地の目安が高く出るので出さない

## 4. あとで考えること

- **時点の補正：** 全部の年を使うマスでは、2015年と2026年の値段の差が残る。最終的には、国土交通省の不動産価格指数（住宅・戸建て）で今の値段に直すことを検討する。指数の地域・期間・ライセンスは、取り込む前に `docs/参考/` に調べる。
- **重複：** 取引価格情報と成約価格情報に同じ取引が載っている可能性。
- **リフォーム：** データの「Renovation」項目を、リフォーム済みの物件と比べるときに使えるか。
- **町より細かい相場：** 町では件数が足りない。近くの町を足す（半径1〜2km、同じ中学校区など）形は、県全体に広げるときに検討する。
- **成約価格情報の取引の事情：** 値が空なので、調停・競売等を外せていない。
