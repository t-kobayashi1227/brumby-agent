# デザイン依頼（Claude Design 用）

段階5で作る2つの画面のデザインをお願いするためのメモです。仕様の正本は `docs/設計まとめ.md` です。段階5に入るまでに用意してもらえれば、段階1〜4の作業は止まりません。

## 共通

- 既存の画面の枠に入れます。左に紺のサイドバー（`ink`）、上に白いヘッダー、本文は薄いグレー（`canvas`）の上に白いカード。強調色は `brand`（`app/globals.css` の色）。フォントは Noto Sans JP。
- 使う人は不動産会社の営業担当者です。販売会議の画面にそのまま出せる、落ち着いた業務画面にします。
- PC の画面（幅 1280px 前後）が主です。印刷（A4）でも崩れないとよいです。
- 距離はすべて「直線○m」と書きます。「徒歩○分」は、入力された駅・バス停の徒歩分だけに使います。

## 画面1：物件情報の入力（/properties/new）

設計まとめ「①物件情報の入力」の15項目です。

| 項目 | 入力の形 | 必須 |
| --- | --- | --- |
| 物件区分 | 新築／中古 | 必須 |
| 価格 | 数字（万円） | 必須 |
| 住所 | 文字（番地まで） | 必須 |
| 交通 | 最大2行。種類（電車／バス）・路線名・駅またはバス停名・徒歩分 | 必須 |
| 間取り | 文字（例：4LDK+S） | 必須 |
| 建物面積・土地面積 | 数字（㎡） | 必須 |
| 駐車台数 | 数字（台） | 必須 |
| 築年数 | 数字（年。新築は0） | 必須 |
| 階数 | 平屋／2階建／3階建以上 | 必須 |
| 庭 | あり／なし | 必須 |
| リフォーム | あり／なし。ありなら年と箇所 | 必須 |
| 特徴ピックアップ | 複数行の文字（物件資料のまとめ書きのまま） | 任意 |
| 競合物件 | 複数行。価格・住所・建物面積・土地面積・築年数 | 任意 |
| 広告予算の総額 | 数字（万円） | 任意 |

動き：

- **交通**：1行目を入れると2行目が使えるようになる。物件資料の「新潟交通バス「○○」停 徒歩3分」をそのまま移せる並び。
- **リフォーム**：「あり」を選ぶと、年と箇所の欄が出る。箇所はキッチン・浴室・トイレ・洗面・内装全面・外壁・屋根・その他から複数選ぶ（チェックボックスかチップ）。
- **位置の確認**：住所を入れると地図にピンが立ち、ドラッグで直せる。「住所から位置を出す」ボタンと、「町丁目の中心に置かれて数百mずれることがあります。ピンを建物の位置に合わせてください」の注意書き。地図の出典（© OpenStreetMap contributors など）を地図の隅に出す。
- **競合物件**：「競合物件を追加」で行が増え、行ごとに削除できる。
- 必須の印、入力の誤りの出し方、保存ボタンと保存後の「戦略を作る」への導線。

## 画面2：販売戦略の一覧（/strategy）

- 物件ごとに1行（またはカード）：所在地、価格、物件区分、間取り、登録日、状態（未実行／実行中／完了／失敗）。
- 行を押すと詳細（/strategy/[id]）を開く。「物件情報を入力する」ボタン。
- 物件が0件のときの表示。

## 画面3：販売戦略の詳細（/strategy/[id]）

上に物件の見出し（所在地・価格・間取り・面積・駅徒歩・駐車）。その下に3つのタブ：**エリア分析／販売戦略／根拠データ**。

### 販売戦略タブ（上から順に）

1. **総合評価**：2〜3文。点数やランクは付けない。
2. **狙う層**：第1〜第3ターゲット（順位の番号つき）と理由。AIが加えた候補には説明（definition）を添える。合わない層は小さく。
3. **訴求ポイント**：最大3つ、優先順位つき。
4. **価格の見方**：位置づけ（割安／相場なみ／割高）と売れやすさ（売れやすい／標準／売れにくい）をラベルで。コメント1〜2文。「周辺の取引と比べた目安であり、価格の査定や保証ではありません」を常に表示。
5. **懸念点と対策**：懸念点と対策案を1組ずつ。
6. **販売の方向性**：1〜2文。
7. **媒体と予算**：推奨媒体（3〜6件）の表（媒体・目的・想定ターゲット・配分%）と円グラフ。総額の入力があれば金額も。
8. **予算シミュレーション**：10万・20万・30万円の列（入力された総額があれば一番左に足す）。表の上に「参考の配分を示した試算です。正式な費用・見積もりではありません。」を常に表示。
9. **出典の一覧**：使ったデータの出典と時点、決まったクレジット文言。

### どのタブにも共通

- **各文の下に小さく「根拠：」**（例：根拠：0〜14歳の割合 15.8%（西区 11.9%））。押すと出典と時点が見える。
- 文は1文およそ40字で、省略せず折り返して全文を出す。
- ページの下に「このレポートは公開データと物件情報をもとにAIが作成した販売戦略の参考です。」

### エリア分析タブ

物件・立地・価格・買い手の4つの分析を、種類ごとに並べる（例：立地なら「暮らしの良い点・不便な点・災害の注意・向く人」）。災害は良い悪いを付けず、事実だけを出す。

### 根拠データタブ

事実シートの表（id・項目・値・比較・出典・時点・状態）。「取得できず」の行は「不明」と表示し、目立たせすぎない。

### 実行中の表示

「戦略を作る」を押してから完了まで数十秒〜数分かかる。進み具合（4つの分析 → メイン → 媒体 → 確認）を出す画面または部品も必要。

## 渡してほしいもの

- 画面ごとのデザイン（HTML の書き出し、またはスクリーンショット）。
- Claude Design のリンクを渡す場合は、Claude Code 側で `/design-login` が必要です。
