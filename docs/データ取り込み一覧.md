# データ取り込み一覧（段階2）

`docs/設計まとめ.md`「使用するデータ（37件）」を、どの順に、どうやってDBに入れるかの一覧です。取得先の詳しい調査は `docs/参考/公的データ調査_2026-10-23.md` にあります。

## 使い方

```
npm run ingest -- <ジョブ名>        # 取り込む（同じデータの古い行は入れ替わる）
npm run ingest -- <ジョブ名> refresh    # 保存済みのファイルを使わず、ダウンロードし直す
npm run ingest -- iryou date=2026-10-24   # オプションは「名前=値」で書く（PowerShell では「--名前」が npm に取られるため）
npm run ingest -- status            # データごとの件数と時点の一覧（段階2の完了条件）
```

- 元データは `data/raw/<フォルダ>/` に置きます（git には入りません）。自動でダウンロードできるものは、ジョブがここに保存します。
- 取り込みは1つのトランザクションで行います。途中で失敗したら全部取り消され、DBは取り込み前のままです。
- 結果は `ingest_logs` に、件数と時点は `datasets` に残ります。

**注1（D09）：** e-Stat 統計GIS には、2020年の新潟県の T001090 のファイルがありません（ダウンロードが404）。D06（T001084）に、一般世帯総数・核家族世帯・6歳未満／18歳未満／65歳以上の世帯員のいる一般世帯総数の列があるため、割合は段階3でプログラムがそこから計算します（例：核家族世帯 ÷ 一般世帯総数。2026-10-25 小林さんと決定）。事実の出典は「e-Stat 国勢調査 T001084（2020）から計算」とします。

**注2（D12・D13）：** 国土数値情報の小学校区・中学校区（A27・A32、API の XKT004・005 と同じ中身）には、新潟市のデータがありません（以前の設計で 2026-10-04 に確認）。設計まとめ「DBを作るときに確かめること」のとおり、新潟市の学区は通学区域一覧（D14）だけで決めます。

**API のジョブについて：** 不動産情報ライブラリの API を呼ぶたびに、利用規約に従って `api_access_logs` に記録します。タイルの API（XKT 系）は図形がタイルの端で切られるため、新潟市にかかるタイルをすべて取り、同じ地物の切れ端を PostGIS で1つにつなぎ直します。
